# wm-otc order relay

Небольшой сервер, через который сайт отправляет заказы и обращения к AI-консультанту
в Telegram. Токен бота хранится **только здесь**, в переменных окружения, и больше
не попадает в браузер посетителей.

## Деплой на Render (бесплатно)

1. Render → **New → Web Service** → этот репозиторий.
2. **Root Directory:** `relay`, **Build Command:** пусто, **Start Command:** `node server.js`.
3. Environment:
   - `TELEGRAM_BOT_TOKEN` — **новый** токен бота (старый был опубликован, его надо отозвать в @BotFather → `/revoke`).
   - `TELEGRAM_CHAT_ID` — ID чата для заказов (например `-1003942536859`).
   - `ALLOWED_ORIGINS` — адрес сайта без слэша в конце, например `https://timur070989-max.github.io`.
     Несколько адресов — через запятую.
4. После деплоя впишите адрес сервиса с `/notify` в `assets/js/config.js`:
   ```js
   var WM_ORDER_RELAY_URL = 'https://<имя-сервиса>.onrender.com/notify';
   ```

## Что делает

- `POST /notify` с JSON `{ "text": "..." }` → `sendMessage` в чат заказов (HTML;
  если Telegram отклонил разметку — повтор простым текстом, чтобы заказ не потерялся).
- Принимает запросы только с адресов из `ALLOWED_ORIGINS`, не больше 10 сообщений
  с одного IP за 10 минут, тело до 16 КБ.
- `GET /healthz` — проверка, что сервис жив.

Бесплатный Render засыпает через ~15 минут без запросов; первый заказ после сна
может идти 30–50 секунд. Сайт ждёт ответа, так что заказ не теряется.
