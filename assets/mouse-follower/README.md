# Персонаж, следящий за мышью

Откройте index.html для демонстрации. Сборка и установка пакетов не нужны.

## Встраивание

Скопируйте папку mouse-follower на сайт. Добавьте в страницу:

```html
<script src="/mouse-follower/mouse-follower.js" defer></script>
<mouse-follower style="--follower-width: 320px"></mouse-follower>
```

Компонент работает на обычном HTML, в WordPress и в других системах, позволяющих подключить свой JavaScript. В React/Next.js подключайте скрипт на стороне браузера и вставляйте этот же пользовательский элемент. Стили изолированы внутри компонента.

Размер задаётся через --follower-width. Пропорции 9:16 сохраняются. Для другого расположения кадров используйте атрибут assets с URL каталога, обязательно с завершающим слешем. По умолчанию assets/ ищется рядом со скриптом.

```html
<mouse-follower assets="/media/character/" style="--follower-width: 260px"></mouse-follower>
```

## Поведение и ограничения

- Направление считается относительно глаз персонажа; движения мыши отслеживаются по всей странице.
- На сенсорном экране персонаж реагирует на касание и движение пальца. Прокрутка страницы остаётся доступной.
- Возле лица и при выходе мыши из страницы возвращается нейтральная поза.
- При системной настройке уменьшения движения показывается неподвижный персонаж.
- Вне экрана анимация приостанавливается. Удаление элемента освобождает обработчики.
- Используются подготовленные кадры исходного видео, без звука и без запросов к внешним сервисам. Это имитация взгляда из доступных поз, а не полноценная 3D-модель. Небольшие изменения тела и переход между концом и началом кругового движения зависят от исходного ролика.
- Белый фон сохранён. Для размещения на цветном фоне понадобится отдельно подготовить материал с прозрачностью.
- Шесть JPEG-атласов занимают около 2,2 МБ; в распакованном виде в браузере — около 71 МБ. Атласы повторно используются несколькими экземплярами блока.

Для встраивания через iframe можно использовать index.html, но внутри iframe персонаж видит указатель только в пределах этого фрейма. Для слежения по всей странице используйте элемент выше.
