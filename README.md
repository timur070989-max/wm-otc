# Онлайн-каталог безрецептурных препаратов World Medicine (в формате DAMAAR)

Современный, премиальный и адаптивный веб-сайт каталога безрецептурных препаратов (OTC) компании **World Medicine Uzbekistan**, выполненный в эстетике и интерактивном формате **DAMAAR.uz**.

## ✨ Особенности проекта

- 🌿 **Премиальный стиль DAMAAR**:
  - Теплая цветовая гамма (натуральные песочно-золотые и изумрудные тона, мягкие тени, `rounded-2xl` карточки)
  - Плавные микро-анимации, зум изображений при наведении и оверлей `«Подробнее →»`
  - Отзывчивый дизайн для смартфонов, планшетов и больших экранов
- 💊 **База безрецептурных препаратов World Medicine**:
  - 24 ключевых безрецептурных препарата и натуральных комплекса (Вамелан, Драстоп Макс, Д-Кальцин, Йодофол, Лацидофорте, Коледан, Полижен, Протекта, Рейтоил, Сановит, Сималгель, Эмфетал, Эслотин и др.)
  - Реальные фотографии с официального сайта World Medicine
  - Подробные составы, дозировки, показания, способ применения и цены в сумах (UZS)
- 🔍 **Умный фильтр и навигация**:
  - Фильтрация по 10 фармакотерапевтическим категориям
  - Алфавитный указатель (А–Я)
  - Фильтрация по форме выпуска (капсулы, таблетки, гели, сиропы, саше)
  - Интерактивный гид по симптомам («Что вас беспокоит?»)
  - Живой поиск в реальном времени
  - Сортировка по популярности, цене и названию
- 🛒 **Интерактивная корзина и оформление заказа**:
  - Выдвижная панель (Slide-over Drawer)
  - Индикатор шкалы бесплатной доставки (от 200 000 сум)
  - Быстрый заказ в 1 клик через **Telegram** с автогенерацией текста заявки
  - Модальное окно оформления заказа с указанием адреса и телефона
  - Сохранение корзины и избранного в `localStorage`
- 🌐 **Мультиязычность**:
  - Полная поддержка двух языков: **Русский (RU)** и **O'zbekcha (UZ)**
- 📖 **Модальная карточка препарата**:
  - Детальный просмотр активных веществ, показаний и инструкции по применению

## 🚀 Как открыть и запустить

1. **Прямое открытие в браузере**:
   Просто откройте файл `index.html` в любом браузере (Chrome, Edge, Safari, Firefox).

2. **Запуск через локальный HTTP-сервер** (рекомендуется):
   - В PowerShell:
     ```powershell
     cd C:\Users\user\.gemini\antigravity\scratch\wm-otc-damaar
     python -m http.server 8080
     ```
   - Откройте в браузере: `http://localhost:8080`
